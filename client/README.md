# BallotChain Client Application

Next.js frontend application for BallotChain — Stellar Soroban Voting dApp.

- **Testnet Tx Hash**: `4a7b57b98d2813dfd5970c679a957a52382f6e911293e506ab68a73b2ef62084`
- **Network**: Stellar Testnet (`https://soroban-testnet.stellar.org`)

## Quickstart

```bash
# Run local development server
npm run dev

# Build for production
npm run build
```

The application uses `@stellar/stellar-sdk` and `@stellar/freighter-api` for on-chain contract interactions.
